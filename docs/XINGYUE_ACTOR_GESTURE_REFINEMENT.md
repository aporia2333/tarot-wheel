# 星月之间 · 人物施法动作精修

2026-10-12，接续水晶控牌 v5。保留自动切牌一次、全部业务牌序、保存计划、四位角色形象和原始素材。

后续已接入逐指关节、独立眼球、袖子网格和发丝随动，详见 [历史管理与角色细节实施报告](XINGYUE_HISTORY_AND_ACTOR_DETAILS.md)。下方内容记录本次后续实施前的状态及当时的验证结果。

## 已实施

- 用已有 `limbs-v1.png` 第三排的收指/握爪姿态建立独立 `grip` 通道。切分前指尖收起，交换时维持牵引，合并完成后放松。主控手保持轻微张力，引导手动作更明确。
- 手背、侧手、掌心三帧仍负责腕部翻转；收指姿态另行驱动，关闭后回到相同悬浮姿态，不在回合之间重置手臂。
- 稳定袖口单独绘制，手势只在腕点以下替换。相反的羽化遮罩连接手与袖口，避免金色刺绣在手势切换时漂移。旧素材降级仍沿用完整手势图。
- 长时间牵引使用单一、不透明的手势轮廓，只在短过渡中混合姿态，避免两组半透明手指长期重叠。较弱张力仅有约 1% 的局部柔化，不冒充逐指骨骼动画。
- 引导手随切分、交换、聚拢做小幅腕部横向牵引，主控手保持水晶侧位置；统一悬浮端点不变，袖口继续与真实腕点相连。
- 视线目标采用当前真实牌组位置的加权中心，面部周边和眼睑固定，只在更小的虹膜区域呈现最多约 1px 的变化；眨眼继续独立运行。
- 魔法渲染器每帧复用一次动作采样，取消此前对 v5 的重复计算。
