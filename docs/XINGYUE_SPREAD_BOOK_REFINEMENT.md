# 星月之间 · 牌阵之书精修

2026-10-12。直接更新正式 `/spreads` 页面，保留牌阵数据、选择与准备流程。

## 设计与结构

书本是主视觉：深绿皮革 `#193225`、古金 `#806132`、羊皮纸 `#eadbb8`、纸面墨色 `#3d3527`、月光纸边 `#f0e3c7`。沿用项目的宋体衬线标题与正文字体；数字采用已有 Georgia。左页章标题配月相细线，右页保留自定义入口；左右纸页各排 2×2 条目录，整次展示 4×2，共八项、两页。手机调整为左右各四条，仍每次显示八项。

- 移除所有目录中的小牌背。每项默认仅显示名称、可直接选择的牌数铭牌；自定义项显示 1–13 张的编辑入口。
- 左右目录留白一致，不在选中时展开内文。细线、纸面亮度和静态星纹保留选中标记；同一时间只有一个牌阵选中。
- 新增小尺寸、可平铺的 SVG 纸纹，皮革封边、多层纸边、细书签、柔和书脊及桌面投影。纹理静态绘制，无逐帧噪声。
- 开始按钮使用古金色铭牌，未选择时弱化，选中后出现一次短暂反光。较矮桌面窗口采用紧凑版型，保留上方人物与完整按钮。

## 交互与动画

- 描述通过 body portal 浮层显示，支持鼠标悬停、键盘聚焦和触屏点击。文字 16px，Esc 或点击外部关闭；鼠标能移入说明继续阅读。
- 使用实际布局尺寸定位浮层，避免入口缩放导致碰撞检测失准；优先避开顶栏、自定义入口、开始按钮和分页区。滚动与窗口变化会重新定位，翻页时关闭浮层。
- 开书仍为 300ms 递近、380ms 开封面。桌面翻页 680ms：四段相连的纸面从书脊翻动，正反面包含真实目录的非交互印刷副本、章标题与页脚；反面条带顺序反转后文字正常阅读。
- 翻页仅动画 transform / opacity，带轻微弯曲、两面厚度、动态投影、边缘高光和末段约 1° 的回弹。没有持续粒子或大面积发光。
- 快速连点由组件内锁拒绝，CSS 动画完成事件不参与业务。翻页结束保留原选择，并将键盘焦点恢复到可用分页按钮。
- 手机、低核数/低内存及不支持 3D 的设备使用 180ms 淡化。`prefers-reduced-motion` 使用 40ms 显示切换，省略转动和反光。设备能力判断是保守启发式，未声称真实性能跑分。
- 计时器、ResizeObserver、MutationObserver 和浮层事件监听均在卸载时清理。浮层只在打开时测量；纸面尺寸仅在布局变化时测量，不逐帧查询布局。

## 实现边界

翻页是四段连续曲面的 CSS 3D 近似，保留了可读的正反面和空间投影，未采用物理纸张仿真。手机保留全部功能，八项目录需要纵向滚动；低性能判断可能把高性能窄屏设备也选为简化模式。后续若需要真实皮革雕花和破损纸缘，可替换静态纹理，不必改变选择逻辑。
