# 星月之间：正式页面统一

2026-10-11。已将第一轮视觉方向接入正式产品路由，复用月窗房间、绒布桌和现有牌面；准备页继续沿用已经确认的水晶球魔法洗切牌。设计预览保留为独立评审入口。

## 页面与布局

| 页面 | 正式路径 | 实现 |
| --- | --- | --- |
| 首页 | / | 直接与当前占卜师交谈，问题输入与弱引导在一个对话框内 |
| 输入问题 | /question | 共用开场对话；背景与示例按需展开，草稿保留 |
| 牌阵 | /spreads | 递书、开书与翻页，16 种牌阵分两组；皮肤、数量、自定义牌位与模板保留 |
| 准备 | /shuffle | 复用既有角色、状态机与洗切动画 |
| 抽牌 | /draw | 绒布桌面，端点 25° 扇形；集中进度、全部重抽和一起翻牌，无牌下文字 |
| 结果 | /result/[id] | 三张以内桌面左右分区；多张牌整桌展开后阅读；手机上下排列 |
| 历史 | /history | 显示记录时间、问题、数量与当次牌面缩略图；使用原记录 ID |
| 登录与账号 | /login、/account | 安静的深绿面板，保留登录、注册、访客、账户安全与原权限检查 |
| 找不到页面 | 不存在的路径 | 同一房间背景，提供返回牌室的入口 |

顶栏继续只保留星月之间、牌面选择、占卜师选择、账号和历史记录。品牌链接统一回正式首页。主体背景、字体、控件、提示、阅读正文与留白使用同一套视觉语言。正文保持至少 16px；手机、平板和桌面均保留可读的长文排版。

结果页展示实际保存的牌面、正逆位与解读。已经保存有效 AI 解读时先呈现解读，再提供折叠的参考牌义；尚未生成时先呈现参考资料，继续沿用原有生成权限、加载状态和追问逻辑。页面没有接入预览中的静态示例解读。

## 已确认业务保持

- 全部 78 张，分两组各 39 张；无可见上下排标签。点击只拿起，向上或向下拖出决定方向，键盘方向键仍可抽牌。
- 基础正逆位在洗牌时确定；向下抽取翻转显示方向，页面视觉不重新抽样，也不改写牌序。
- 已抽牌背可在既有区域内自由摆放；刷新恢复摆放。全部重抽只清空选择，保留原牌序与基础正逆位。
- 抽齐后等待点击一起翻牌，继续沿用保存与失败重试流程；记录 ID、保存数量、牌位顺序与本地/云端历史逻辑保留。
- 洗切动画、角色、动作计划与原子提交没有改动；仍是洗牌后自动魔法切一次。
- 牌阵数量、自定义牌位、模板、AI 解读、追问、登录与授权没有新增接口或改变存储键。
- 历史缩略图复用结果页的旧牌面解析，兼容只有旧图片路径和名称的快照，不重写旧记录。
