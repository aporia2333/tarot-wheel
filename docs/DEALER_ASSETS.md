# 塔罗师与准备场景素材规范（R05 / R05.1）

## 当前资源

四个角色保留原稳定 ID：星月 `star-moon`、学者 `scholar`、曲奇猫 `quqi`、星帽猫 `star-cap`。人形使用 `atlas-v2.png`，猫形使用 `atlas-v3.png`；各目录的 `manifest.json` 指向当前版本。`atlas-v1.png` 保留为历史资源，猫形 v2 为未采用的生成迭代，不由当前页面加载。

场景独立分层：`public/scenes/preparation/room-v1.png` 是空房间背景，`table-v1.png` 是透明绒布木桌。角色、手、牌和微粒在代码中分别合成；背景图片不含牌组或人物。牌背继续使用用户当前皮肤。

本轮全部 PNG 由 Codex 内置 imagegen 生成。网站没有新增生图服务、付费依赖或密钥。精确提示词在 `output/design/r05-production-prompts.json` 和 `r05-feline-refinement-prompts.json`。

各头部保留完整耳朵、头发或帽子。猫形强化自然猫口鼻、胡须、三角耳和毛绒短爪，收起尖爪；托牌手含粉色肉垫，不使用人类手指或人类发型。人形采用成年比例的插画形象。服装为深绿和克制金色细节。

SVG 按 manifest 裁切原透明 PNG，不转码或破坏 alpha。头部水平裁切已按角色校准，少数区域稍跨名义格边以保留耳朵。躯干按完整格比例显示，用舞台轮廓遮住生成图集里的静态袖子，避免将中心窄裁切拉宽。上臂、前臂和三种手势独立定位。

2026-10-11：`DealerArm` 在现有臂部区域内只采样上部布料，排除上臂／前臂图集里的多余袖口。手部素材自带的袖口成为唯一腕口，跟随前臂角度，连接处重叠并轻微渐隐。共用 135/105px 双关节比例，待机与所有准备动作都采用同一连接方式；PNG 和 manifest 保持原样。

魔法抬手使用现有的张开手背、侧握、托掌三个姿势，先抬前臂再转腕，侧面投影适度收窄。短暂纹理混合连接三个姿势，侧握阶段保持单一完整轮廓以减少手指／猫爪重影；收手反向过渡。手和袖口共用同一腕部锚点，图集加载和牌面切换保留当前转腕进度。没有新增 PNG，旧准备动作仍使用原固定手势。

## Manifest 与动画

`src/data/dealerCharacters.ts` 定义并注册四个 JSON：

- `atlas / version / legacyAtlas / grid`：当前资源、版本、旧资源、网格。
- `canvas`：统一舞台 1000×650；手机使用中部裁切视窗。
- `parts`：`[列, 行, 格内 x, 格内 y, 格内宽, 格内高]`，比例坐标。
- `anchors`：头、躯干、肩、待机手、逻辑牌组和桌面起点。当前头 `[500,148]`、躯干 `[500,310]`、桌面 y=390；逻辑牌组仍为 `[500,430]`。
- `states`：idle/talk/shuffle/cut/finish 映射到表情；闭眼与思考作为独立演出表情。
- `actions`：七个动作均使用 `rig`。左右手共用操作计划的牌包位置与时间轴，并依动作选择张开、夹持、托牌。

舞台将逻辑牌包纵向投影到桌面：普通动作 y+70，旧桌面混洗围绕 y=500 压缩纵深。旧演出最多绘制 12 个代表牌包；魔法演出绘制所有实际牌包，并用实际牌数表示牌叠厚度。新的切牌保持平放投影，逐叠移动，再从底向顶合叠。保存的牌序、随机切点和正逆位仍由同一计划决定。

角色切换采用关闭状态下不加载选项的浮层；动作进行时锁定切换。当前图集加载失败时保留基础形象并继续执行。减少动态效果时关闭呼吸、眨眼、微粒、镜头和光晕，操作仍按同一计划提交。

## 已知美术限制

当前为 SVG 分层骨骼和关键手势演出，尚未制作独立口型、耳朵骨骼和逐指握牌。自动生成的袖子在极端角度仍可能出现接缝；少量头部的颈部边缘在表情切换时仍可继续精修。素材加载占用约 2–2.7 MB/角色，房间与桌子合计约 4.3 MB；首次打开需下载图片，选项图集只在打开角色浮层时加载。若后续手工补绘，保持格位、身份、光线、透明背景和腕口位置，再更新 manifest。
