# 水晶球魔法洗切牌

2026-10-11 更新。正式准备页和动作预览使用同一套演出。

## 交互

洗牌次数仍可自己指定 1–10 次，或交给占卜师决定 2–4 次。洗完后直接进行一次魔法切牌；切牌次数输入、选择和开始按钮均已移除。切牌完成、牌组落桌后自动进入抽牌页。

新进入切牌阶段的会话执行一次切牌。已经保存且正在执行的旧切牌计划继续按原计划完成，避免修改用户正在进行的阅读。

## 动作与视觉

| 段落 | 演出 |
| --- | --- |
| 唤醒 | 一只手／猫爪靠近水晶球，另一只张开引导；球内微光逐渐增强 |
| 浮起 | 牌组缓慢离开桌面，桌面投影随高度变淡 |
| 展开 | 连续牌包在空中展开，手与牌保持间距 |
| 重组 | 牌包沿上下错开的弧线换位；洗牌计划中的翻转同步表现为 180° 转动 |
| 收拢 | 按已保存的最终顺序，从底向顶合拢牌包 |
| 落桌 | 合并后的牌组减速回到桌面，水晶微光随之收敛 |
| 收手 | 双手回到休息位置，再接下一轮或进入抽牌 |

洗牌沿用上述浮空展开演出。切牌单独采用“唤醒 → 逐叠提起和放开 → 短暂停顿 → 逐叠按顺序合回 → 收手”，连续牌包保持平放，不穿插包内牌，不旋转翻面。每一叠的厚度来自实际牌数；分叠和合叠时每次只有一个牌包移动，合叠按最终顺序从底向顶完成。

单轮洗牌 6.8 秒、新切牌 5.6 秒；多轮中间轮次缩短 20%。保存的旧魔法切牌仍保留原 4.6 秒演出。减少动态效果模式使用 650ms 静态落牌，保留相同数据提交。

沿用现有房间、桌子、四个占卜师的分层素材与牌背。新增水晶球使用 SVG 玻璃高光、青铜底座和内部纹理。魔法只有细线、十颗低亮度微粒和局部微光，没有全屏闪光。手臂采用原有固定长度双关节，猫角色使用带肉垫的托举猫爪。

袖子与手部图集原先都带着完整袖口，叠加后出现重复袖口。现通过 SVG 裁切保留上臂和前臂布料，手部保留唯一袖口；手的旋转继承前臂，只允许小幅腕部角度变化。上下臂使用 135/105px 比例，让肘部向下放松，连接处使用小范围透明遮罩重叠。该连接同时用于待机、洗牌、切牌及旧动作，不修改原 PNG。旧动作超出当前骨骼可达范围时按原腕位置连接，保留其历史动作与牌序。

抬手先提升前臂，再向外伸展与转腕；水晶一侧的手略先动作，抬手用整段演出的前 22% 完成。手部从待机手背开始，经过侧握再展开掌心，复用图集的三种手势，在侧面略收窄投影并短暂混合纹理。袖口锚点始终固定在前臂末端，收手时先转回手背再放下，避免操作挂载或完成时突然换手势。该转腕只影响演出采样，不修改保存的牌包关键位置、动作版本、时长或真实牌序。减少动态效果仍直接显示回到待机位置的手背。

## 真实牌序与恢复

洗牌标记为 `motionVersion: 3`，新的逐叠切牌标记为 `motionVersion: 4`；会话存储版本和存储键继续沿用。无版本旧动作、`motionVersion: 2` 的过手动作及上一版魔法切牌仍可恢复。新切牌严格校验逐叠时间轴，未修改切点、最终收集顺序或正逆位逻辑。

操作开始前保存全部 78 张牌、连续牌包、收集顺序、翻转标记和关键位置。动画渲染每一个实际牌包，按同一计划采样轨迹；播放期间不会重新生成随机数。完成后仍通过现有操作 ID 原子提交，重复回调不能再次洗牌。

切牌保留包内顺序和基础正逆位。刷新会重播当前保存计划，已完成动作不会重复。切换牌面保留当前播放进度；执行期间禁止切换占卜师。

- `src/lib/crystalMagicMotion.ts`：关键位置、浮空弧线、手势、投影和水晶能量采样。
- `src/components/preparation/CrystalBall.tsx`：玻璃水晶球与局部微光。
- `src/components/preparation/MagicPreparationRig.tsx`：完整牌包、固定长度双关节手臂与逐帧 SVG 变换。
- `src/components/preparation/DealerArm.tsx`、`src/lib/dealerArmRig.ts`：布料裁切、袖口与手的共同变换、连接与关节比例。
- `src/components/preparation/CardPacket.tsx`：有厚度的牌叠与平放投影，也用于准备前后静止牌组。
- `src/components/PreparationScene.tsx`：魔法演出接入、旧动画兼容、素材降级与完成回调。
- `src/lib/preparation.ts`、`preparationMotion.ts`、`src/store/readingFlowStore.ts`：新计划、严格恢复校验、时长与幂等提交。
- `src/app/shuffle/page.tsx`、`preparation.css`：自动切牌与场景布局。
- `src/app/design-preview/page.tsx`、`preview.css`：可分别播放洗牌、切牌的样例。

每帧直接更新 SVG 变换和透明度，不重渲染角色图集与 React 整棵组件树。没有新增生产 npm 依赖或外部素材请求。

角色沿用二维分层素材，手／猫爪是关键姿势，尚不具备逐根手指连续弯曲的三维骨骼。手机覆盖浏览器触屏仿真，真机帧率仍受设备性能影响。
